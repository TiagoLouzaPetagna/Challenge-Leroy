# Fontes

Fontes usadas para aproximar a tipografia de Papers, Please.

Fontes baixadas do DaFont:

- BM Mini, BitmapMania: https://www.dafont.com/bm-mini.font
- BM Germar, BitmapMania: https://www.dafont.com/bm-germar.font
- PixelPlay, Aleksander Shevchuk: https://www.dafont.com/pixelplay.font
- Nokia Cellphone FC, Zeh Fernando: https://www.dafont.com/nokia-cellphone.font

A pagina da Papers Please Wiki lista essas fontes como usadas ou derivadas no jogo:
https://papersplease.fandom.com/wiki/Fonts

Antes de publicar comercialmente, confira os arquivos de licenca/readme dentro de cada pacote.
